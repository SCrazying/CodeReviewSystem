## 产品结构

```
CodeReviewSystem/
├── docs/          # 本文档中心
├── client/        # Electron 桌面客户端(提交树/审查/自动修复)
└── server/        # Node.js 服务端(REST API + 管理 Web + 定时任务)
```

## 核心能力一览

- 🔒 客户端授权门禁:连不上服务端 → 禁用审查
- 🌳 Git 提交树:仓库/分支切换、仅当前分支/全部分支、MR 徽标、单提交审查
- 🤖 MR 全自动审查 + 评论自动回填(Gitea/GitLab)
- 🔧 自动修复分支:基于 MR 源分支,每问题一个 commit,仅存本地
- 📊 服务端统计:问题分类/模块/团队维度量化、token 用量与请求次数
- ⏰ 定时任务:选仓库定时审查、失败重试、执行历史
- 🐘 PostgreSQL 统一数据源,数据可导出归档

## 实施里程碑

M1 服务端基础 → M2 客户端升级 → M3 提交树+审查 → M4 自动修复 → M5 管理 Web+统计 → M6 定时任务 → M7 打包发布
