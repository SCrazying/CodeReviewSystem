# CodeReviewSystem 文档

| 文档 | 用途 |
|---|---|
| [PRD.md](PRD.md) | 需求说明: 功能需求(审查/回填/修复/定时/历史/设置)、非功能需求、边界 |
| [方案设计.md](方案设计.md) | 总体架构、关键设计决策(D1~D11)、核心流程、接口清单、配置设计 |

配套:根目录 [README.md](../README.md) 提供项目简介与快速开始。
